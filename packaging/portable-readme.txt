tt_fish · 钓鱼助手 v1.6.1

本包适用于64位 Windows 10或11，已包含Python、Tk界面及图像识别依赖。
不需要安装Python、Anaconda或PyCharm，启动时不联网下载组件。

1. 将整个压缩包解压到可写目录，例如桌面上的独立文件夹。
2. 双击“启动钓鱼助手.bat”。请保留同目录的app和runtime文件夹。
3. 打开雷电或MuMu模拟器，设置空格映射；在助手第1步选择模拟器种类及游戏窗口，再框选完整游戏画面。
4. 点击第3步开启监测，切回模拟器按F8开始；F9暂停。
   快捷键以界面当前设置为准。首次打开不会自动按键。

空格应映射到圆形钓鱼按钮下半部与“开心收下”按钮重叠的位置。
选区要保留完整游戏及游戏内部底栏，排除模拟器标题栏、工具栏和外侧黑边。
详细图文说明及框选示例见 app/README.md，也可在程序里打开框选示例。

默认勾选不停钓，每6个基准帧截图一次，识别预览默认隐藏。
截图间隔调小可提高识别响应，电脑卡顿时可调大以降低采样频率。
正常运行不自动保存轨迹、截图或诊断包，暂停和F9不会导出测试数据。
本机设置、校准速度、主动保存的截图或录像，以及启动错误日志保存在data中。
升级时先退出旧版，将新包解压到新文件夹；需要保留设置时，复制旧data中的config.json和speed_profile.json。
从源码版升级可将项目目录中的这两个文件复制到新包的data中，不存在的文件无需创建。
首次升级会勾选不停钓，并将旧默认截图间隔30改为6；其他自定义间隔、快捷键与等待设置保留。
窗口大小或显示比例改变后请重新框选。不要把自己的data上传到GitHub或发给他人。

无法启动时运行“检查运行环境.bat”；启动错误写入data/logs/startup.log。
不要在压缩包预览窗口中直接运行。不要只复制bat文件或单独的pythonw.exe。
模拟器若以管理员运行，助手也需使用相同权限；无需默认开启管理员权限。
本程序不包含雷电或MuMu模拟器和游戏，不支持32位Windows、macOS或Linux实时操作。

项目免费提供，仅供学习交流，无需购买授权或激活码。
图像识别及键盘操作不代表不会被游戏检测，使用前请确认游戏和平台允许。
