# 本地数据与公开发布

运行程序不需要注册、账号密码或API密钥。图像在本机处理；程序没有遥测、自动上传、远程指令或联网识别。点击界面中的项目或作者链接时，才调用默认浏览器访问该链接。

| 位置 | 内容 | 是否放入公开源码包 |
|---|---|---|
| `config.example.json` | 默认设置，框选信息为空 | 是 |
| `assets/templates/` | 局部控件图，不含玩家昵称、排名或聊天面板 | 是 |
| `docs/images/` | 使用说明示例 | 是 |
| `config.json` | 本机设置、窗口标题、窗口尺寸与选区 | 否 |
| `logs/` | 本地状态、动作、错误；异常可能含本机路径 | 否 |
| `snapshots/`、`recordings/` | 游戏截图和录像，可能包含昵称或聊天 | 否 |
| `support/`、`replay_output/` | 诊断包和离线分析输出 | 否 |

`.gitignore` 排除运行数据和常见本地环境文件，但不会删除已经提交进Git历史的文件，也不能替代人工检查。公开更新请运行 `python build_release.py`，它按明确文件清单生成 `dist/tt_fish-版本号.zip`，不会打包额外的个人文件。

`make_support_bundle.py` 默认只包含公开源文件。附加日志使用 `--include-logs`；该选项中的配置已去掉窗口框选和未知字段，但日志本身不保证匿名。截图和录像分别需要 `--include-screenshots`、`--include-video`。这些附加数据可能含个人信息，分享前应逐项检查；程序不会自动发送诊断包。

GitHub问题反馈中优先提供版本、状态提示和复现步骤。不要公开账号密码、聊天记录、个人目录、未经检查的录像或完整本机配置。
